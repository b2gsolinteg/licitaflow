# RC31.9 · Descoberta simples

Objetivo: manter o LicitaNexo Essential simples para iniciantes e rápido para encontrar editais.

Principais decisões:

- o card mostra o nome do órgão no topo; o número de controle PNCP permanece apenas para integrações e links oficiais;
- a página inicial oferece busca direta e atalhos por Estado, Cidade, Modalidade e site da disputa;
- existe uma consulta dedicada por site da disputa, além do filtro já disponível na busca;
- o menu lateral pode usar peso visual maior para facilitar a navegação, enquanto o conteúdo principal permanece leve;
- `Top 50` passa a ser apresentado como `Em destaque`;
- `Meus Editais`, `Analisar Edital` e `Minha Empresa` continuam fora do Essential;
- nenhuma migration ou alteração de dados é necessária nesta versão.
